# BERD-multilabel-bronchoscopy
Multi-label classification of 23 bronchoscopic findings on the BERD dataset. Benchmarks ResNet-50, EfficientNet-B3, ViT-B/16, Swin-T, and Hybrid-EffSwin (EfficientNet-B3 + Swin-T). Includes loss ablation (BCE/ASL), fusion strategy ablation, per-class threshold optimization, and BOHB hyperparameter search.
